# CLI Calculator

A command-line calculator built with JavaScript and Node.js.

## Features

- Addition, subtraction, multiplication, and division
- Command-line arguments using `process.argv`
- Missing and empty argument validation
- Invalid number validation
- Division-by-zero handling
- Case-insensitive operations
- Exit codes for errors

## Usage

```bash
node index.js add 10 5
node index.js subtract 10 5
node index.js multiply 10 5
node index.js divide 10 5
```
